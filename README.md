# CodeStudy — Turn YouTube Playlists into Coding Courses

Video, editor, terminal and notes in one resizable workspace. Progress and streaks are tracked automatically, and your work pushes straight to GitHub.

## Features

- **Import Playlists**: Turn any YouTube coding playlist into a structured course.
- **Interactive Workspace**: Side-by-side video, code editor, and live terminal execution.
- **Notes & Snippets**: Timestamped notes linked to video playback.
- **Progress Tracking**: Daily targets, streaks, and watch time statistics.
- **GitHub Integration**: Commit and push lesson code straight to your GitHub repositories.

## Development

Make sure you have Node.js installed.

```sh
npm install
npm run dev
```

## Tech Stack

- TanStack Start & TanStack Router
- React 19
- Tailwind CSS
- Monaco Editor & XTerm.js
- Supabase
